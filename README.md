O mnie

Z wykształcenia jestem monterem elektronikiem. Interesuję się sprzętem komputerowym, diagnostyką usterek, systemami Windows oraz sieciami komputerowymi.

Posiadam praktyczne umiejętności w zakresie:

* składania i modernizacji komputerów,
* diagnostyki oraz serwisowania laptopów,
* instalacji i konfiguracji systemu Windows,
* instalacji sterowników i podstawowej konfiguracji oprogramowania,
* naprawy smartfonów i wymiany podzespołów.

Nauka i rozwój

* Ukończony kurs CompTIA A+ Core 1 (220-1201) na Udemy.
* Przygotowanie do egzaminu CompTIA A+.
* Rozwijanie wiedzy z zakresu sprzętu, systemów operacyjnych, sieci i diagnostyki.

Moje projekty

W tym repozytorium będę dokumentować ćwiczenia, przykłady diagnostyki, konfiguracje oraz rozwiązane problemy techniczne.

Obszary tematyczne

* Sprzęt komputerowy
* Windows
* Sieci komputerowe
* Naprawy urządzeń
* Diagnostyka i rozwiązywanie problemów

Cel
